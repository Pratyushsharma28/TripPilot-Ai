# TripPilot AI ✈️

**AI-powered travel planning and budget optimization for Indian travellers.**

TripPilot AI helps travellers compare transportation options, explore flexible travel dates, and plan journeys around their budgets.

## 🚀 Project Overview

Planning a trip often involves checking multiple travel platforms, comparing prices, and manually working out which combination best fits your budget.

TripPilot aims to simplify this process through AI-assisted research and intelligent travel comparison.

Users can enter their starting city, destination, travel dates, trip duration, number of travellers, budget, and preferred transportation modes.

## ✨ Planned Features

- **City Autocomplete:** Get city suggestions while entering locations.
- **Flexible Date Planning:** Explore different departure dates and trip durations.
- **Multi-Transport Comparison:** Compare train, bus, and flight options.
- **Budget Optimization:** Identify options that best fit the user's budget.
- **AI-Assisted Research:** Use Gemini and TinyFish for travel research and analysis.
- **Results Dashboard:** View and compare available journey options.

## 💻 Run the Frontend Locally

### 1. Clone the repository

```bash
git clone https://github.com/Pratyushsharma28/TripPilot-Ai.git
```

### 2. Open the project

```bash
cd TripPilot-Ai/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 🔐 Environment Variables

Private API credentials must be stored in backend environment variables and must never be committed to GitHub.

A `.env.example` file can document required variable names without containing actual secrets.
